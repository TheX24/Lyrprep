# Contributing to Spicy Lyrics

Thanks for your interest in contributing!

## Code Contributions

All code is licensed under the project's main license (see `LICENSE`).

## Media Contributions

All media (images, GIFs, videos, audio, etc.) must be licensed under **CC0 1.0** (public domain).

### What this means

By contributing media, you waive all rights to it. Anyone can use, modify, and distribute it without attribution or restriction.

### How to contribute media

1. Ensure you own the rights to the media.
2. Add your files to the `media/` directory using this structure:
```
media/{your-username}/filename.png

media/{your-username}/subfolder/filename.gif
```
3. In your PR description, confirm:
> I license these files under CC0 1.0
4. A maintainer will review and upload accepted files to our CDN.

### What we won't accept

- Media under any license other than CC0
- Custom or revocable licenses
- Licenses with takedown clauses
- Content you don't have rights to

## Questions?

Open an issue if you're unsure about anything.
